## 3. 分域控制评估

### 3.1 认证与授权
- 统一认证依赖 `get_current_user` / `require_permission` 覆盖受保护接口，权限判定在服务端执行，不依赖前端隐藏。
- 密码 bcrypt 哈希存储；登录失败限流、会话带过期与撤销机制。
- 敏感读接口（如巡检任务）按细粒度权限（`inspection:read`）收敛，非任意登录用户可得。
- **评估：符合。** 无越权读取路径的已知缺口。

### 3.2 凭据与加密
- 设备 SSH 口令、SNMP 团体字、远程同步私钥/API Key 均 Fernet 加密落库，密钥（`CREDENTIAL_SECRET_KEY`）与数据库分离存储。
- 密钥生成兼容新旧存储格式，单密钥可解存量数据；缺密钥场景有处理。
- API 响应统一脱敏：`SNMP_COMMUNITY_MASK="******"` 序列化层生效，更新端点剥离掩码防写回。
- **评估：符合。** 凭据不以明文经普通 API 暴露。

### 3.3 网络访问与扫描
- 扫描目标经合法性校验，ip_range 规模上限（≤1024 主机/任务）、并发上限（1–100）、连接超时约束到位。
- 设备连接走线程池/异步子进程，不阻塞事件循环；任务可取消。
- 出站 URL 做 SSRF 防护：配置期与请求期共用同一策略，拦截私网/链路本地/元数据地址（含 `169.254.169.254`），支持主机白名单。
- **评估：符合。** 无「用户输入直接执行任意命令/扫描任意网络」的路径。

### 3.4 数据备份与容灾
- 设备配置备份：设备级互斥锁防并发损坏；diff 基线只取成功备份；失败记录独立落库、不阻断批次。
- 备份文件访问：下载/删除经文件名白名单 + realpath 目录内校验，防目录穿越；操作写审计。
- 数据库备份：pg_dump custom 压缩；SHA-256 完整性指纹；运行台账自动裁剪。
- 恢复校验：pg_restore 进隔离库 `cornerstone_verify` 抽查后销毁，**不触碰生产库**。
- 异地同步：命令一律 argv 构造、无 shell 解释；源目录白名单；传输后落地一致性校验；失败告警。
- **评估：符合。** 备份链具备完整性、授权与可恢复性保障。

### 3.5 AI 调用
- AI API Key 加密存储；外部调用前做敏感数据口径处理。
- AI 仅输出分析/建议，**无任何设备写命令下发路径**，不驱动网络变更。
- 调用设超时与异常隔离，单模型失败不影响核心运维功能。
- **评估：符合。** 符合「AI 分析→人工审批→执行→验证→留痕」的演进约束。

### 3.6 平台与部署
- 容器非 root 运行；无 `changeme` 类弱默认口令；缺关键配置时以随机强密码/拒绝启动兜底。
- 生产默认不创建演示账号/数据（`seed_demo_data=False`）。
- 迁移幂等、启动自动应用；pg 客户端与数据库服务器大版本对齐。
- **评估：良好。** 传输层 TLS 见 §5。

### 3.7 日志与审计
- 关键操作全量审计，含操作人身份。
- 日志/响应不输出设备口令等敏感值。
- 运维类历史（备份/同步运行）独立台账留痕，与「人的操作问责」审计分离。
- **评估：良好。**
